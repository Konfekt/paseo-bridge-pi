# Jobs from subagents

The top-level Jobs view keeps its existing direct background-job rows and output
expansion. A separate **From subagents** heading groups jobs from verified native
worker descendants, including deeper descendants. Rows, completed filtering,
output styling, and observation-only adopted-job labels are unchanged. No job
control operations are added. Agents, inline task views, and chat are unaffected.

The producer, not the bridge filesystem or browser, authorizes this inventory:
private retained group/manifest nonce identities are matched to actual worker
session headers. Infrastructure, unrelated sessions, and unverifiable branches
are excluded. Invalid retained history produces an explicit notice rather than
invented ownership. Idle/reaped worker history remains usable only while its
retained evidence still verifies.

Both the list and selected output use the same transitive scope; ancestry and
metadata are checked again before returning output. Snapshot-bound job pages
are exhausted and deduplicated by job ID for the view and Work indicator. A
changed inventory, repeated cursor, or capacity limit produces an error instead
of silently showing a partial count. Selected output remains UTF-8 bounded and
read-only; reading it does not acknowledge notifications or start retention.

Already-running Pi sessions need a user-initiated `/reload` after deployment to
publish the updated producer. Do not remotely reload a responding/compacting
session or infer success from fresh-fixture results for an older runtime.
